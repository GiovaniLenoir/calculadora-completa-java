# 🧮 calculadora-completa-java

Uma calculadora completa desenvolvida em **Java puro** com **Programação Orientada a Objetos (POO)**.  
Ela funciona no **terminal (linha de comando)** e oferece operações básicas, avançadas e histórico de uso.

---

## 📌 Funcionalidades

- ✅ Soma, subtração, multiplicação e divisão
- ✅ Potência e raiz quadrada
- ✅ Porcentagem (ex: 20% de 150 = 30)
- ✅ Histórico de operações realizadas
- ✅ Validação de entradas (evita erros como divisão por zero)
- ✅ Interface simples via terminal
- ✅ Código organizado em **classes separadas**

---

## 🗂 Estrutura do Projeto

- CalculadoraPOO/
- ├── Main.java // Interação com o usuário
- ├── Calculadora.java // Lógica das operações
- └── Historico.java // Armazena e exibe o histórico

## 🧑‍💻 Exemplo de Uso

Após iniciar, você verá um menu com opções para escolher a operação desejada.
Digite o número correspondente e siga as instruções para inserir os números.

=== CALCULADORA JAVA ===

Escolha uma operação:
[1] Soma (+)
[2] Subtração (-)
[3] Multiplicação (*)
[4] Divisão (/)
[5] Potência (^)
[6] Raiz quadrada (√)
[7] Porcentagem (%)
[8] Ver histórico
[0] Sair
